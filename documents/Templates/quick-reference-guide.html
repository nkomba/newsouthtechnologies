How to Generate a PDF from Any Template

  1. Open the HTML file in your browser (Chrome, Firefox, or Edge). Double-click the file or drag it into a browser window.
  2. Replace bracketed fields — use Ctrl+F to find each [PLACEHOLDER] and type the real value. Use Ctrl+H (Find and Replace) for repeating fields like [PHONE].
  3. Review the page — scroll through and verify all content looks correct. No bracketed placeholders should remain.
  4. Click "Print / Save as PDF" — the button appears in the top-right corner of every template.
  5. Configure print settings:
    • Destination: Save as PDF
    • Layout: Portrait
    • Margins: None (CSS handles internal margins)
    • Scale: 100%
    • Paper size: Letter (8.5" × 11")
    • Check: Background graphics (enabled)
  6. Save the file using the naming convention: [TYPE]_[CLIENT]_[YYYY-MM-DD].pdf
  7. Verify the PDF — open and review the saved PDF before sending to the client.

Pro Tips

Efficiency

  • Keep a master "find-and-replace" list of your company details so you can quickly paste them into Find & Replace when editing a template.
  • Save filled-in versions — when you customize a template for a specific client, save a copy in \documents\executed\ with the naming convention.
  • Use browser bookmarks — bookmark each template file for quick access.
  • Create client subfolders — once volume grows, organize executed PDFs by client name in the \executed\ folder.

Quality Control

  • Always test-print a new template the first time you use it to verify layout and pagination.
  • Check page breaks — for multi-page documents, ensure content doesn't awkwardly split across pages. Adjust the print scaling slightly if needed.
  • Proofread after replacing placeholders — search for any remaining [ brackets to catch missed fields.
  • Verify on mobile — if the client may view the PDF on a phone, check readability at small sizes.

Legal Document Notice

⚠ Before Using Legal Templates

The following documents contain legal language and should be reviewed by qualified legal counsel before first use:

• Master Services Agreement (MSA) — the umbrella contract for all engagements

• Mutual NDA — confidentiality agreement

• Engagement Letter — binding commitment letter

• Statement of Work (SOW) — contractual deliverables and acceptance criteria

Recommended: Have an attorney review these once, approve the master templates, and then team members can safely customize the bracketed fields for each client without altering the legal language.
