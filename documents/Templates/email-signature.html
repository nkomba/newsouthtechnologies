How to Install This Signature in Outlook:
  1. Open Outlook → File → Options → Mail → Signatures
  2. Create a new signature, name it "NewSouth Default"
  3. Select all the signature below this box (from the divider line down to the social icons)
  4. Copy (Ctrl+C) and paste (Ctrl+V) into the Outlook signature editor
  5. Replace bracketed fields with your real details
  6. Save and set as default for new messages and replies
