1. Scope & Methodology

This review covers the complete static website codebase for New South Technologies: 9 HTML pages, 1 JavaScript file, 4 CSS files, and associated SVG assets. The review was conducted by static analysis — reading all source files and cross-referencing asset references, link targets, and API integrations.

Areas inspected: HTML structure & accessibility, JavaScript logic & dead code, CSS correctness & variable definitions, form integrations, internal link integrity, image references, SEO metadata, and consent management (Cookiebot).

Issues that produce visible defects or broken functionality for end users. Must be resolved before launch.

3. Medium Priority Findings

Issues affecting functionality, maintainability, or user trust. Address before or shortly after launch.
ID File Finding Severity
M-01 careers.html (all 7 job cards) All "Apply" buttons link to the wrong position. Every Apply button uses ?position=grc-lead regardless of the role. Clicking Apply for any of the 7 positions pre-selects "GRC Lead" in the dropdown. The URL parameter logic works correctly — the links just need correct position= values per job card. Medium
M-02 js/main.js:66–96 Partially commented function with live orphan code. initMobileMenu() was commented out incrementally. Lines 90–96 are not commented out — they reference navLinks and toggleBtn which are only declared inside comments. Additionally, initBlogFilter() is defined but never called; its logic is re-implemented inline in DOMContentLoaded, creating a dead function and duplicate logic. Medium
M-03 css/style.css Undefined CSS custom properties. The slider section uses var(--font-size-3xl), var(--font-size-2xl), var(--font-size-sm), and var(--shadow-lg) — none defined in :root. The root only defines --shadow-md and spacing/color tokens. These resolve to initial, meaning the slider container has no shadow and layer labels have no design-system font size. Medium
M-04 blog.html:312, careers.html:459 Privacy Policy links are dead (#) on secondary pages. Footers on both pages use href="#" for Privacy Policy and Terms. index.html correctly links to privacy-policy.html. Users submitting forms on blog.html or careers.html cannot reach the Privacy Policy — a compliance concern given PII collection on those pages. Medium
M-05 index.html:117, 135 Missing space in HTML attribute syntax. Two img tags have alt=""aria-hidden="true" without a space separator. This is a syntax error that will fail HTML validation and may cause unexpected parsing in stricter environments. Medium
M-06 careers.html:369 Label and accept attribute mismatch on file upload. The resume field label reads "PDF Only, Max 5MB" but the input accepts .pdf,.doc,.docx. Misleading — candidates may think Word documents are rejected. Medium
M-07 blog.html, careers.html Cookiebot consent manager missing on secondary pages. The Cookiebot CMP script loads only on index.html. The blog.html newsletter form and careers.html application form (collecting PII including phone, location, and clearance status) operate without a consent gate. If subject to GDPR, CCPA, or similar requirements, this is a compliance gap. Medium

4. Low Priority & Informational Findings

Minor issues and best-practice notes. No functional impact; address in a maintenance pass.
ID Area Finding Severity
L-01 SEO Favicon file exists (assets/images/favicon.svg) but no <link rel="icon"> tag is present on any page. Browser tab shows a generic icon. Low
L-02 SEO Missing canonical link tags on index.html, blog.html, and careers.html. Blog article pages correctly include them. Top-level pages are exposed to duplicate-content indexing issues. Low
L-03 Social / SEO No Open Graph or Twitter Card meta tags on any page. Sharing on LinkedIn or X produces a plain-text link card with no image or description — a missed visibility opportunity for a B2B firm targeting agency leadership. Low
L-04 JSON-LD Organization schema in cmmc-calculator.html contains a placeholder phone number (+1-555-123-4567). If surfaced in a Google Knowledge Panel this would display a fictional number. Low
L-05 CSS --transition: all 0.3s ease is applied broadly. Transitioning all properties can cause unnecessary paint/composite work. Scope to transform, box-shadow, background-color. Low
L-06 CSS Three overlapping @media blocks target mobile nav at 768px and 900px breakpoints with redundant rules on the same elements. The cascade resolves this correctly but maintenance is difficult. Consolidation recommended. Low
L-07 HTML "Coming Soon" blog card has data-category="all", which hides it when any specific filter is active (the filter checks for exact string matches). Semantically incorrect; consider removing the attribute or using a neutral value. Info
L-08 HTML Terms of Service link in index.html footer is href="#" with no target page. Given the firm's compliance-first positioning, the absence of published Terms is a credibility gap. Info
L-09 Forms careers.html has an empty _replyto hidden field with a comment noting it should be populated via JS — but no JS does this. Remove it or implement the intended email population. Info
